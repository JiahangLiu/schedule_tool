# 课表解析与空闲时段计算工具 (Schedule Tool)

这是一个基于纯 Python 开发的命令行课表小工具。它能够读入学生课表，智能合并连续课程，并高效计算个人或多人的空闲时间段。

本项目完全基于 Python 标准库实现，**无需安装任何第三方依赖**，代码采用模块化设计，结构清晰，逻辑严谨，非常适合作为 Python 基础与算法入门的实战练习。

##  核心功能

本项目分为三个主要需求模块，并分别对应 GitHub 上的三次 Pull Request 开发记录：

### 需求 1：读入课表
- **双模式输入**：支持“手动逐行录入”或“从 CSV 文件批量读入”。
- **时间格式校验**：能够自动识别并拦截非法的格式（如 `25:00` 或 `08:60`），并兼容中文全角标点（如中文冒号、中文逗号）。
- **文本视图打印**：将零散的课表按“周一”至“周日”分组排版，并按照开始时间先后排序，输出清晰直观的本周课表。

### 需求 2：算空闲时段
- **连续课程合并**：给定每天可用时间范围（默认 08:00 - 22:00），智能合并相邻课程（如 `09:00-09:45` 和 `09:55-10:40` 会自动合并为 `09:00-10:40`），拒绝碎片化空闲。
- **空闲时间排序**：算出每天的空闲时段，并按照**时长从长到短**（越长越靠前）的顺序进行排序输出。

### 需求 3：找共同空闲时间
- **多人课表输入**：支持循环录入多人的课表。
- **求交集算法**：基于“双指针算法”高效求出多人的共同空闲时段。
- **排序输出**：最终结果同样按照“时长越长越靠前”排序，方便用户快速找到可支配的最长公共时间。

## 本项目在算法层面做了以下优化：

- 统一时间度量：将所有 HH:MM 字符串统一转换为“当天从 00:00 开始计算的分钟数”。这样一来，复杂的跨时段比较和加减法直接变成了整数运算，大大简化了逻辑。

- 区间合并算法：通过按开始时间排序，依次比较相邻区间，如果结束时间和下一个开始时间的间隔小于等于某个阈值（本项目设为20分钟），则合并为一个大的区间。

- 双指针求交集：在求多人的共同空闲时，使用双指针分别遍历两人的空闲列表，通过比较 max(开始时间) 和 min(结束时间) 计算重叠区。谁的结束时间更早谁就向后移动，将时间复杂度优化至 O(N+M)。
